# 종족별 전략 메모 (사용자 도메인 지식 + 봇 관찰)

봇 종족별 보강 시 참고. 평균점수 랭킹은 DECISIONS.md.
**공통 관찰(최대 발견)**: 봇은 전 종족에서 **확장 연구(terra+nav+gaia)를 사람의 절반만** 올려 행성 못 늘림 → 저득점. 종족 특화 전에 글로벌 확장연구 상향이 1순위 레버.

## nevlas (현 최하위, 평균 56)
- **정체성**: 의회(PI)가 강력 — **파워 토큰을 2배 효율로** 굴리는 파워 엔진. 파워액션 반값(봇 `hasNevlasPI`→`effPowerCost=ceil(c/2)` 반영됨). 시작: science1, 4O/2K/15C/1Q, 파워 2/4/0, PI수입 4파워+1토큰. 홈=ice.
- **사용자 전략**: 의회로 토큰을 모으는 공급원을 노린다 — **4파워 기술타일(`tech-act-4p`)**, **+2 3그릇(bowl3) 토큰 인공물**, **7VP+2토큰(bowl3) 우주선 연방(`ship-fed-7vp3p2t`)** 등. 즉 토큰 확보 → PI로 2배 → 파워액션 폭발.
- **봇 실패 관찰(1게임)**: terra0/nav1/gaia0 (exp=1.0), 과학4/경제2만 → 파워·지식만 쌓고 **확장을 안 함** → 39점. 파워 엔진은 *수단*이고 결국 그 파워로 **테라포밍/사거리 올려 행성 건설**해야 점수. 봇은 그 전환을 못 함.
- **보강 방향(가설)**: ① 의회 조기 건설(이미 earlyPiAllowed에 있음) ② 토큰 공급원(4p타일/+2토큰 인공물/7vp3p2t 연방) 우선 ③ **+ 확장 연구·건설**(글로벌 레버와 함께). 측정엔 **종족 강제 배정 필요**(랜덤이면 신호 1/4 희석).

## geodens (평균 61, 2순위 보강) — 사용자 도메인 지식 2026-06-18
- **정체성**: 의회(PI) 보유 시 **처음 먹는 행성 유형마다 즉시 +3K**. → "새 유형을 빨리·많이" 먹는 게 핵심 엔진(지식 폭발).
- **기본 빌드 오더(정석)**: ① **의회를 먼저** 짓는다(3K 보너스 활성화) → ② 그 뒤부터 새 유형을 하나씩 먹어 3K씩 챙김.
- **시작 보너스 타일 선호**: **1삽(테라포밍 1단계 할인) + 즉발 포머(즉포) 보너스 타일**. 원삽(1단계 테라) 땅 + 보라(가이아) 땅 + 즉포가 한 지역에 붙어있으면 **최상의 시작 포지션**.
- **초반 먹잇감**: 의회 짓고 **원삽땅 2개 + 가이아땅 + 소행성** 등 → 다양한 유형으로 3K 연쇄 + 확장.
- **연구**: **거리(nav) 2단계 / 테라포밍 3단계를 빠르게**. 다음 라운드부터도 *아직 안 먹은 유형이 있으면 바로바로 먹으며* 확장+지식.
- **3TF 주의**: 집을 많이 뿌려 **광석 수익이 든든하지 않으면 1~3라운드엔 3TF(3단계 테라포밍 땅) 거의 안 노림**(비용 과다).
- **원시행성(proto)**: 인공물 또는 **우주선 연방**으로 노리기도.
- **약점=돈**: 확장 위주라 광석·지식은 풍부한데 **크레딧이 만성 부족** → **7C 파워액션 / 크레딧 연방**을 자주 먹어 메꿈. (크레딧 연방 = 우주선 **8VP+8Credit**이 최상 — 놓치지 말 것.)
- **후반**: 유형을 많이 먹어뒀으니 **이클립스 2QIC(행성유형당 VP)가 매우 효율적**. **테라 5단계 보너스 / 고급 기술타일**도 자주 노림.
- **봇 보강 포인트(가설)**: 봇이 ①의회-퍼스트 ②"미보유 유형 우선 확장" ③크레딧 부족시 7C/6C 보충 ④후반 이클립스2Q 가치(앞 qicVpGate와 연결) 를 못 하고 있을 가능성. 측정 시 geodens 강제 배정 필요.

## lantids (평균 62, 3순위) — 사용자 도메인 지식 2026-06-18
- **정체성**: **기생 광산** — 남의 행성에 광산 설치(테라포밍 불필요). 의회 보유가 기생의 전제.
- **갈림길 = 상대 밀집도에 따라 3분기**:
  1. **상대가 밀집한 지역이 있으면(최상)**: **의회로 시작 → 점프 1번으로 붙고 → 기생광산 ~4개 뿌리기**. 빠른 확장.
  2. **상대가 흩어져 있고 내 주변에 내 땅이 있으면**: 먼저 **Nav2 올리고 집을 뿌려 초반 자원 확보** → 3~4라운드쯤 의회 준비해 기생.
  3. **주변에 내 땅도 없으면**: **경제 2칸** 올려 기술트랙으로 자원 확보 → 의회 짓고 **QIC 활용해 기생**.
- **시작 보너스 타일**: 보통 **+1광물 타일**. **4지식으로 테라포밍 올리면 10광물**이 준비돼 그 빌드를 완성(테라 올리는 타이밍이 자원 트리거).
- **★기생 갯수 주의(중요 룰)**: 기생을 다 해버리면 **교역소로 업글할 광산이 없어짐**. 마지막 1~2개는 남겨둬야 함 → **마지막 라운드 막턴이 아니면 기생광산 총 8개가 되지 않도록** 관리.
- **약점=돈**: geodens처럼 광산은 기생으로 쉽게 뿌리지만 **크레딧 부족** → **7C 액션 / 크레딧 연방**(우주선 8VP+8Credit 최상)으로 보충.
- **봇 보강 포인트(가설)**: ①상대 밀집도 판단해 의회-점프-기생 스타트 ②기생 8개 캡(교역소 여지 남기기) ③크레딧 보충 ④Nav2/경제2 분기 선택. 측정 시 lantids 강제 배정 필요.

## itars (평균 63, 4순위) — 사용자 도메인 지식 2026-06-18
- **난이도**: 높음(토큰 제어 까다로움). 정체성: **의회(PI) = 가이아 구역에 쌓인 파워 토큰을 태워 기술타일 획득** 엔진.
- **핵심 콤보(PI 발동 라운드)**: 가이아 구역에 토큰을 **최소 8개** 모아 **그 라운드/다음 라운드에 기술타일 2개**를 먹는다. 토큰 보내는 법:
  - **프리액션으로 파워토큰 태워 2개**를 가이아 공간으로 + **가이아포밍 던져서 6개** → 합 8개.
  - 고수는 토큰 제어로 **3개(=12토큰)**도 먹지만 어려움.
- **정석 빌드 오더**: ① 수익 타일 1개 정도 먹으며 **경제 2칸** 올림 → ② **다음 라운드 의회 짓고** 위 "가이아포밍 + 프리액션" 콤보로 **기술타일 2개 획득** → ③ 의회 이후엔 **매 턴 기술타일 ~2개씩** 먹으며 발전.
- **아카데미도 좋은 편** (기술 엔진과 시너지).
- **보너스 타일 선호**: **2토큰 + O(광물) 타일** (토큰 공급).
- **자원 운영 특징**: 토큰이 계속 소진되니 **3파워 → 토큰 2개 추가 프리액션을 다른 종족보다 훨씬 자주** 사용. **광물도 종종 토큰으로 변환**해 엔진 유지.
- **봇 보강 포인트(가설)**: ①의회 전 가이아 구역 토큰 ≥8 적재(가이아포밍+토큰소각) 셋업 ②의회 후 매턴 기술타일 2개 우선 ③토큰 보충용 3pw→2토큰 프리액션 적극 ④2토큰+O 타일 선호. 봇이 "토큰을 가이아로 보내 기술타일 2개" 콤보 셋업을 못 할 가능성 큼(난이도↑). 측정 시 itars 강제 배정.
