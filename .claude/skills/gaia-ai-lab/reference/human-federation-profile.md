# 사람 연방 프로파일 (목표 — 봇이 따라가야 할 패턴)

출처: `data/human-games` 19게임에서 추출한 **사람 연방 137개** (종족 무관 — 연방은 종족 상관없이 비슷하게 구성되므로 표본 충분). 추출: `fullGameLog`의 `action:"Federation"` 항목(round/details "N satellites, P power"/다음 Federation Reward).

## 핵심 수치 (사람)

| 항목 | 값 |
|---|---|
| 위성 수 | 평균 **1.55**, **44%가 0개**(밀집 클러스터로 형성), 5+ 거의 없음 |
| 파워 | 대부분 **딱 7**(최소로 닫음) |
| 형성 라운드 | R1~R5 고르게 + R6 몰아치기(전체의 ~27%) — **일찍·자주** |
| 플레이어당 연방 수 | **4.17** |
| 보상 선호 | `fed-7vp-2o`(광물, 최다) > `fed-8vp-1q` > `fed-12vp` > … (광물 > 돈 확인) |

## 봇 대비 (병목)

| | 사람 | 봇 |
|---|---|---|
| 연방 수/명 | 4.17 | **1.29** |
| 위성/연방 | 1.55 | **5.93** |

봇 = 흩뿌린 집을 한 방에 거대 연방(위성 5.9)으로 1.3개. 사람 = 클러스터로 싸게(위성 0~2) 4.2개.

## 설계 함의 (사용자 모델)

1. **전체 파워 7 넘어도 다 안 묶음** → 딱 7짜리 최소 연방 + 나머지는 다음 연방 씨앗. (= `fedMinTrim` 의도)
2. **싸게(위성 0~2)·일찍·자주**. 위성 많이 드는 연방은 사람도 기피.
3. 블런트 캡/예산은 **금지**(기각이력 −2.99 등: 위성 막으면 연방 자체를 못 만듦). 형성을 막지 말고 "작게 자주"로 유도.

## 측정 대상
- `fedMinTrim`(최소부분집합 트림) — 이 프로파일의 #1 직접 구현. 단 밀집 컴포넌트 케이스에만 발동(흩어진 빌드엔 제한적일 수 있음 → 결과 보고 일반화 판단).
