2. **연방 형성 평가 수정** — 봇이 연방을 회피하던 평가 버그(형성 시 보상 VP 미반영) 교정.

## 3. 핵심 결론
- 봇의 86→224 격차는 **단일 평가/휴리스틱 노브로 안 닫힘** (이번 2건 + 과거 13건 ≈ 15건 null/negative).
- 진짜 병목: **다턴 빌드오더 조율**. 대표 예 = 고급타일은 "랩/아카데미 건설 + 트랙 L4 + 초록연방"이 같은 턴에 맞아야 획득 가능한데, 봇은 랩을 트랙 저레벨일 때 일찍 지어 평생 0개.
- 셀프플레이는 전략 개선을 검증 못 함(동급 약봇끼리). **head2head는 do-no-harm 게이트로만**, 진짜 검증은 사용자 1:3 실전.

## 4. 권장 (다음 단계, 효과 큰 순)
1. **고급타일 도달 정책** — 초록연방+L4트랙 보유 시 랩/아카데미 건설을 유도해 고급타일 획득(순수 +VP, 기회비용 없음). 구조적이라 평가함수가 아닌 정책/계획 변경 필요. (가장 큰 단일 레버)
2. **종족별 전략 차별화** — 순한 프로파일이 do-no-harm이면 채택(사용자 명시 요구). 사람 1:3 실전으로 실효 검증.
3. **연방 형성 정책** — 형성 시점 평가에 보상 VP 반영(현재 보상이 별도 단계라 과소평가).
