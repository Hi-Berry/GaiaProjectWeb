# AI 봇 강화 — 측정 기반 진단 (2026-06-08)

목표: 봇 점수 대폭 상향(사용자 요청 "평균 180"). 결론부터: **현재 평가함수 구조로는 self-play 승자 ~85가 천장이고, 격리된 손잡이 조정으로는 안 깨진다.** 아래는 그 근거와, 진짜로 점수를 올리려면 무엇을 건드려야 하는지.

## 측정 인프라
- `npm run head2head` — 챔피언 vs 도전자를 같은 테이블에 앉혀 승률·VP마진을 유의성과 함께 측정(좌석 6패턴 회전으로 편향 상쇄). 자세히는 `HEAD_TO_HEAD.md`.
- 베이스라인(self-play 4봇): 150ms → avg 63.5 / 승자 84.3 (20판). 1000ms → avg 64.0 / 승자 85.7 (12판). **생각시간 6.7배도 변화 거의 없음.**

## 중대 정정: 180은 규칙상 불가능이 아님
초기에 "바닐라 Gaia 4인 총합 ~400-550 → 180 불가능"이라 단정한 것은 **틀렸다**. 이 구현은 우주선/트와일라잇 인공물/이클립스 등 커스텀 콘텐츠로 VP가 인플레된 변형이며, 사용자에 따르면 강한 사람은 **270-300점**을 낸다. 따라서 180은 달성 가능하고, 봇의 self-play 승자 ~85는 천장이 아니라 **강한 플레이의 ~1/3 수준으로 약한 것**. 위 7개 tweak null은 천장이 아니라 약한 정책에 대한 미세 조정이었을 뿐. (단, data/human-games의 365판은 전부 봇 게임 — 실제 강한 사람 플레이 데이터는 아직 0판.)

## 학습형(B) 1차 시도 — 가치망 leaf eval (실패, 유의)
- 파이프라인 구축: features.ts(33특징) → valueNet.ts(순수 TS MLP) → valueData.ts(자기대국 수집) → trainValueNet.ts → evaluator `useValueNet` 연결.
- 17,434 샘플 학습: 검증 MAE 7.56 VP (기준선 15.27의 절반) — **예측기로는 우수**.
- head2head(60판, useValueNet vs 휴리스틱): 도전자 **33.3% 승, VP −11.59 (p<0.001)** — 유의하게 **더 약함**.
- 교훈(전형적 함정): 약한 정책 게임으로 회귀학습한 가치망을 MCTS에 그대로 꽂으면 **탐색이 망의 외삽 오류를 악용**해 휴리스틱보다 못하다. 해결은 (a) 정책+가치 동시학습, (b) 자기 탐색이 만든 상태로 반복학습, (c) 정책 prior로 탐색 유도 — 즉 **제대로 된 AlphaZero 루프**(다일 규모) 또는 **강한 사람 데이터로 학습**(현재 0판, 1:3 필요).

## Capstone (expandDrive + scriptedStrategy)
 뿌리인 확장을 *직접* 강하게 보상해도 null(−1.4)이고, 가장 큰 단일 액션(연방)을 MCTS 우회해 *강제 실행*해도 null(+0.76). 즉 **가치 평가도, 단일 액션 강제 실행도** 안 먹힌다. 7가지 범주(탐색량·가중치·후보순서·행동게이팅·우주선점수·확장보상·연방강제) 전부 무효 — 봇의 약점은 단일 지점이 아니라 **다턴에 걸친 빌드오더 전체를 엮지 못하는 구조적 한계**다. 단일 스크립트 규칙으로도 안 풀리며, 포괄적 빌드오더 계획 엔진(사람 플레이 근거) 또는 학습형 정책이 필요하다. 봇은 확장·연방·연구를 충분히 높게 평가하지만 "경제→확장→연결→연방→연구5" 시퀀스를 엮지 못한다. 그래서 평가함수/가중치/후보 어떤 조정도 효과가 없다(6번 실험으로 확증). 깰 수 있는 것은 (a) 강한 사람 플레이로부터 추출한 **명시적 다턴 전략(빌드오더) 스크립팅**, 또는 (b) **학습형 정책/가치망(RL)** 뿐. 둘 다 사용자 입력(1:3 로그)·결정 필요.

## 근본 진단 (21,068 플레이어 로그 분포)
- **연방 수: 0=12%, 1=70%, 2=17%, 3=1.6%.** → 70%가 연방 1개에서 멈춤(강한 플레이 2-3개).
- **L5 트랙 수: 0=70%, 1=30%, 2=0.4%.** → 70%가 연구 5단을 한 트랙도 못 감.
- **점수 분포: 40-60 최빈, 평균 57.5, 100+ 단 2%.**
- 구조물 8-11개(강한 플레이 12-16개) → **확장 부족**이 사슬의 뿌리: 적은 구조물 → 2번째 연방 클러스터(파워7) 불가 → 소득 부족 → 연구 5단 불가.
- 우주선: 입장 26,979회 vs 액션 ~9,200회 — 입장 66%가 액션 없이 -5VP. 단, head2head에선 게이팅이 중립(입장비용 절감 = 액션이득 손실 상쇄).

## 진짜 점수를 올리려면 (격리 손잡이 X)
봇은 연방·연구를 **가치는 알지만(가중치 높음) 다턴에 걸쳐 도달을 못 함**. MCTS(깊이8)+근시안 롤아웃이 "지금 광산 1개"는 보지만 "3턴 후 2번째 연방"은 못 봄. 필요한 것:
1. **사람 플레이 기반 재설계** — 강한 사람의 1:3 게임(`humanGameLogger`가 `data/human-games/`에 자동 저장)을 봇 수순과 비교해, 확장/연방/연구 타이밍의 다턴 원칙을 추출해 후보생성·롤아웃 정책을 구조적으로 교체. (추측 아닌 근거 기반 — null을 깰 유일한 입력)
2. **학습형(RL) 가치망** — 자기대국으로 가치/정책망 학습. 천장 상향 가능하나 별도 파이프라인(며칠).

## 야간 강화 시도 로그 (head2head, 가중치 고정)
- **iter1 `useGoalPlanner`** (평가 바이어스: 연구페이스·우주선액션·소행성·adv-pass·연방페이스): 36판 → 도전자 **33.3% 승, VP −4.3 (p=0.046)** → **유의하게 더 약함, 기각.** 평가 바이어스는 MCTS 국소최적화를 교란 → 재확인: 약점은 가치가 아니라 다턴 실행.
- **iter2 `deepRollout`** (롤아웃 메인액션 1→5회 연쇄, 스텝 6→14, 수입 미반영): 60판/400ms → 도전자 **51.7% 승, VP +0.88 (p=0.76)** → 중립. 한계: 수입 미반영이라 다라운드 경제를 못 봄.
- **iter3 `deepRollout`+`rolloutIncome`** (가상 라운드 사이 구조물 기반 수입 근사): 60판 +3.83(p=0.097)로 유망했으나 **n=120 확정에서 +1.82 (p=0.378)로 회귀 → null.** n=60 신호는 노이즈였음(확정 측정의 중요성). 채택 안 함.
  → **종합**: 탐색·평가·롤아웃·수입근사·가치망(약데이터) 모든 자율 레버가 ≤+2VP(확정 불가). 봇 ~85는 휴리스틱+얕은MCTS 구조의 천장. 돌파엔 **강한 사람 데이터 다수 수집(dev:collect로 특징 캡처) → 모방학습/가치망** 또는 **풀 AlphaZero**(다일) 필요. 현재 강한 게임 1판(273, 행동일지뿐·특징 미캡처).
- **shipEngineBonus v1** (사용액션×35 + 체감보상 탑승잠재): 60판 → 49.2%승, VP −3.03 (p=0.25) → null(음수 기운). 탑승 잠재가치(b)가 과탑승 유발 의심 → (a)사용액션만 남긴 v2로 재검증.
- **shipEngineBonus v2** (사용액션×35만): 60판 → VP −3.30 (p=0.21) → null(같은 음수 기운). 우주선 eval 보너스는 v1/v2 모두 기각 — 봇끼리에선 더 좋은 액션을 밀어냄. 코드 유지(flag off).
