# AI 봇 강화 — 측정 기반 진단 (2026-06-08)

목표: 봇 점수 대폭 상향(사용자 요청 "평균 180"). 결론부터: **현재 평가함수 구조로는 self-play 승자 ~85가 천장이고, 격리된 손잡이 조정으로는 안 깨진다.** 아래는 그 근거와, 진짜로 점수를 올리려면 무엇을 건드려야 하는지.

## 측정 인프라
- `npm run head2head` — 챔피언 vs 도전자를 같은 테이블에 앉혀 승률·VP마진을 유의성과 함께 측정(좌석 6패턴 회전으로 편향 상쇄). 자세히는 `HEAD_TO_HEAD.md`.
- 베이스라인(self-play 4봇): 150ms → avg 63.5 / 승자 84.3 (20판). 1000ms → avg 64.0 / 승자 85.7 (12판). **생각시간 6.7배도 변화 거의 없음.**

**Capstone (expandDrive)**: 뿌리인 확장을 *직접* 강하게 보상해도 null(−1.4). 결론 확정 — 문제는 **가치 평가가 아니라 다턴 실행/계획**이다. 봇은 확장·연방·연구를 충분히 높게 평가하지만 "경제→확장→연결→연방→연구5" 시퀀스를 엮지 못한다. 그래서 평가함수/가중치/후보 어떤 조정도 효과가 없다(6번 실험으로 확증). 깰 수 있는 것은 (a) 강한 사람 플레이로부터 추출한 **명시적 다턴 전략(빌드오더) 스크립팅**, 또는 (b) **학습형 정책/가치망(RL)** 뿐. 둘 다 사용자 입력(1:3 로그)·결정 필요.

## 근본 진단 (21,068 플레이어 로그 분포)
- **연방 수: 0=12%, 1=70%, 2=17%, 3=1.6%.** → 70%가 연방 1개에서 멈춤(강한 플레이 2-3개).
- **L5 트랙 수: 0=70%, 1=30%, 2=0.4%.** → 70%가 연구 5단을 한 트랙도 못 감.
- **점수 분포: 40-60 최빈, 평균 57.5, 100+ 단 2%.**
- 구조물 8-11개(강한 플레이 12-16개) → **확장 부족**이 사슬의 뿌리: 적은 구조물 → 2번째 연방 클러스터(파워7) 불가 → 소득 부족 → 연구 5단 불가.
- 우주선: 입장 26,979회 vs 액션 ~9,200회 — 입장 66%가 액션 없이 -5VP. 단, head2head에선 게이팅이 중립(입장비용 절감 = 액션이득 손실 상쇄).

## 진짜 점수를 올리려면 (격리 손잡이 X)
봇은 연방·연구를 **가치는 알지만(가중치 높음) 다턴에 걸쳐 도달을 못 함**. MCTS(깊이8)+근시안 롤아웃이 "지금 광산 1개"는 보지만 "3턴 후 2번째 연방"은 못 봄. 필요한 것:
1. **사람 플레이 기반 재설계** — 강한 사람의 1:3 게임(`humanGameLogger`가 `data/human-games/`에 자동 저장)을 봇 수순과 비교해, 확장/연방/연구 타이밍의 다턴 원칙을 추출해 후보생성·롤아웃 정책을 구조적으로 교체. (추측 아닌 근거 기반 — null을 깰 유일한 입력)
2. **학습형(RL) 가치망** — 자기대국으로 가치/정책망 학습. 천장 상향 가능하나 별도 파이프라인(며칠).
