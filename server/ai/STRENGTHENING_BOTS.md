# AI 봇 강화: 150+ VP 목표

현재 봇은 **MCTS(몬테카를로 트리 탐색)** + **휴리스틱 Evaluator**로 동작합니다.  
강화 학습이나 자기대국으로 실력을 끌어올리는 것은 **같은 코드베이스로 충분히 가능**합니다.

---

## 1. 현재 구조 요약

| 요소 | 위치 | 역할 |
|------|------|------|
| **MCTS** | `mcts.ts` | 후보 액션들에 대해 시뮬레이션 후 최선의 수 선택 (현재 3초, 깊이 5) |
| **Evaluator** | `evaluator.ts` | 상태 점수화 (VP, 자원, 건물, 연구, 연방 등) — MCTS가 이 점수를 사용 |
| **BotLogic** | `bot.ts` | 후보 수 생성(`getCandidateMoves`) + MCTS 호출 + 실제 행동 실행 |

시뮬레이션(롤아웃)에서는 `getNextMove(..., isSimulate: true)`로 **첫 번째 후보만** 쓰고 있어, 탐색 품질이 제한적일 수 있습니다.

---

## 2. 강화 방법 (난이도·효과 순)

### A. MCTS·Evaluator만 강화 (바로 적용 가능)

- **MCTS 시간/깊이 늘리기**  
  - `mcts.ts`: `MAX_TIME_MS`(예: 3000 → 5000~8000), `MAX_DEPTH`(5 → 6~8)  
  - 수천 판이 아니라 **한 판당 생각 시간**을 늘려서 실력 향상.
- **Evaluator 보정**  
  - `evaluator.ts`에서 **최종 VP와 상관이 높은 항목** 비중을 키우기 (연방, 연구 5단, 건물 수, 라운드 미션 등).  
  - 150+ VP 게임 로그를 몇 판 수집해서, “그런 게임에서 점수 높았던 상태”를 반영해 계수 조정.
- **롤아웃 품질**  
  - 시뮬레이션에서 `getNextMove(isSimulate: true)` 대신 **Evaluator로 그리디** 선택하거나, 상위 2~3개 후보 중 랜덤 등으로 조금 더 나은 롤아웃을 쓰면 MCTS 품질이 올라갑니다.

→ **코드만으로 가능**하며, 지금 구조에서 파일 몇 개 수정으로 진행할 수 있습니다.

---

### B. 자기대국으로 Evaluator 튜닝 (반자동)

목표: **수천 판 자기대국**을 돌리면서, “실제 최종 VP가 높은 게임”에서 쓰인 상태일수록 Evaluator 점수가 높게 나오도록 조정.

1. **자기대국 러너** (구현됨: `server/ai/selfPlayRunner.ts`)  
   - **서버를 띄운 상태**에서 소켓 클라이언트로 `create_game` → `auto_setup_test({ gameId, selfPlay: true })` 호출.  
   - `selfPlay: true`이면 호스트 슬롯도 봇으로 간주해 **4인 전부 봇**이 한 판을 끝까지 진행.  
   - 매 판 종료 시 각 플레이어의 **최종 VP**를 수집하고, 옵션으로 JSON 파일에 저장 가능.  
   - **실행 방법**  
     - 터미널 1: `npm run dev` (서버 실행)  
     - 터미널 2: `npm run self-play` (기본 10판)  
     - `SELF_PLAY_GAMES=100 npm run self-play` — 100판  
     - `SELF_PLAY_OUTPUT=./data/selfplay.json npm run self-play` — 결과를 JSON으로 저장 (휴리스틱 튜닝용)  
     - `SELF_PLAY_PORT=5000` — 서버 포트 (기본 5000)
2. **데이터로 Evaluator 보정**  
   - 방법 1: **그리드 서치**  
     - Evaluator 계수 후보(가중치 조합)를 정해 두고, 각 조합으로 N판씩 자기대국 → 평균 VP·승률이 높은 조합 채택.  
   - 방법 2: **회귀**  
     - “상태 스냅샷 → 해당 플레이어의 최종 VP”를 맞추는 회귀 모델을 두고, Evaluator 수식을 그 예측에 가깝게 조정(손으로 계수 바꾸거나, 간단한 최적화 스크립트).

→ **자기대국 러너는 구현 완료.** 서버만 켜두고 `npm run self-play`로 N판 돌린 뒤, 수집한 VP로 Evaluator/MCTS 파라미터를 튜닝하면 됩니다.

---

### C. 강화 학습 (RL) / AlphaZero 스타일 (장기 과제)

- **정책·가치 네트워크**로 수를 두고, 자기대국 결과(승/패, 최종 VP)로 학습.  
- 상태 → 신경망 → (행동 확률, 예상 VP) 예측, MCTS는 그 네트워크로 노드 확장·롤아웃·평가.
- TensorFlow.js(Node에서) 또는 Python 서버로 학습 파이프라인을 두고, 현재 게임 상태 인코딩/액션 공간 정의가 필요합니다.

→ **같은 게임 규칙·상태 구조를 쓰면 이론상 가능**하지만, 설계·구현량이 크고 “코드 몇 줄” 수준은 아닙니다.

---

## 3. 150+ VP를 노리려면

- **단기:**  
  - MCTS 시간·깊이를 늘리고, Evaluator에서 **연방·연구 5단·고가치 건물·라운드 미션** 비중을 키우기.  
  - 150+ VP를 기록한 게임이 있다면, 그때의 라운드별 상태를 보고 “그런 상태일수록 Evaluator 점수가 높다”고 조정.
- **중기:**  
  - 자기대국 러너를 만들어 수천 판 돌리고, 위처럼 Evaluator 계수를 데이터로 튜닝.  
  - 동시에 롤아웃을 그리디/상위후보 랜덤으로 바꿔서 MCTS 품질 향상.
- **장기:**  
  - RL/네트워크 기반 정책 도입을 검토.

요약하면, **강화 학습이나 자기대국으로 150+ VP를 노리는 것은 현재 코드 구조로 충분히 가능**하고, 먼저 MCTS·Evaluator와 자기대국 러너부터 손대는 것을 추천합니다.
