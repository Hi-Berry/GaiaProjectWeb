## 해석(10-06)
- 탐색을 3배 늘려도(48→160) +2.3±3.5로 유의한 개선 없음 → 병목은 탐색량이 아니라 평가 품질
  (가치망 상관 0.42, 상대를 MCTS 없는 빠른 봇으로 가정) 과 정책망이 '기존 봇 흉내'라는 점.
- 흉내 정확도가 29→42%로 올라도 greedy는 거의 그대로(−30→−27) — 흉내만으로는 기존 봇을 못 넘는다.
- 다음: 자기 강화(탐색 방문 분포를 정책 목표로, 실제 결과를 가치 목표로 재학습 반복).

## 자기 강화 1회(10-06)
- v1 PUCT 48 × 4좌석 자가대국 4.5시간 223판(결정 47,357) + 기존 봇 데이터 30%로 v1에서 이어 학습(3에포크, 최고 = 1에포크).
- 대결 Δ −17.0 → −10.6(같은 판 짝 +6.4). 탐색량 3배(+2.3)보다 한 번의 자기 강화가 더 큼 → 반복을 계속할 가치.
- 검증 지표(정책 top-1·가치 상관)는 거의 그대로 — 검증 목표가 '자가대국 방문 분포 + 봇 라벨' 혼합이라 강도 지표로는 둔감. 판정은 대결로.

## 자기 강화 2회(10-07) — 정체
- v3는 v2보다 나아지지 않음(같은 판 짝 −3.5±3.4, 노이즈 범위). v1 대비 +2.9±3.3 → v1→v2의 +6.4도 일부는 운이었을 가능성.
- 검증 지표(정책 top-1 42%·가치 상관 0.40)는 v1부터 3회 연속 제자리. 학습 손실만 내려감.
- 추정 원인: ① 가치망 상관 0.4 + 시뮬 48회 → 방문 분포가 정책 사전확률과 거의 같아 '자기 강화 목표'에 새 정보가 적음
  ② 탐색 안에서 상대를 기존 봇 빠른 경로로 가정(자가대국 실제 상대는 PUCT) ③ 72판 대결의 표준오차 ±3.4로 7점 미만 변화는 판정 불가.

## 가치망 강화(10-07) — 데이터로는 한계
- 가치용 판 수 ~20배(빠른 봇 2.6만 판) + 루트Q 혼합 목표 → 가치 상관 0.43 → 0.46(R1 .25→.30, R6 .60→.63)뿐, 대결 개선 없음.
- R6(점수 거의 확정)에서도 상관 0.63 → 데이터 양보다 입력 표현이 병목일 가능성: 인코더에 '현재 기준 예상 최종 점수'
  (최종 미션 진행도·연구 트랙 점수·잔여 자원 환산·남은 라운드 미션/수입 전망)가 직접 들어 있지 않다.
- v1 이후 4개 모델(v2 −10.6, v3 −14.2, v4 −13.2)이 같은 대역 — v2의 개선은 일부 운이었을 가능성이 크다. 현 구조는 Δ ≈ −13에서 정체.
